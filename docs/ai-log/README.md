# AI 협업 기록

DayFit은 **테크 리드(나) + AI 구현** 방식으로 개발한다 ([decisions.md](../decisions.md) 2026-11-18).
이 폴더는 내가 AI에게 무엇을 지시했고, 결과를 어떻게 검토했고, 무엇을 반려하거나 바꿨는지 남기는 기록이다.

- 하루에 파일 하나: `YYYY-MM-DD.md`
- 작업 단위마다 아래 형식으로 한 덩어리
- **지시·결과**는 AI가 초안을 쓰고, **검토**는 내가 직접 쓴다
- API 키, 비밀 값, 개인 정보는 적지 않는다

## 형식

```md
## HH:MM 작업 이름

- 지시: 내가 정한 요구사항과 규칙 (요약)
- 결과: 바뀐 파일, 동작
- 검토: 직접 써보고 확인한 것 / 반려한 것과 이유
- 트러블슈팅: (있으면) 문제 → 원인 → 해결
- 결정: (있으면) decisions.md에 남긴 결정
```
